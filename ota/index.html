NIMmesh

Offline Bluetooth-mesh payments on Nimiq.
Direct install — no TestFlight, no codes.

Install NIMmesh
1. Open this page in Safari on the iPhone (not Chrome, not the TestFlight app).
2. Tap Install NIMmesh, then Install on the system prompt.
3. Go to the Home Screen — the icon appears and downloads in a few seconds.
4. No trust step needed (distribution-signed). Valid until June 2027.

Android

Download the APK
1. Tap Download the APK in any browser.
2. Open the downloaded file. Android asks once whether to allow installs from that browser; say yes.
3. Open NIMmesh and allow Bluetooth so your phone can relay.
4. Android 12 or newer. No account, no registration, no device limit.

Ad Hoc build — installs only on registered devices. v0.89.4 (the app wears its own mark: teal mesh hexagon on the splash, menus, install page, and home-screen icon; NIM gold stays NIM)
